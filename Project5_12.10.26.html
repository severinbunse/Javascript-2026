Project 5: JS Libraries (Nov 12 – Dec 10, 2026)


Select one of the JavaScript libraries introduced in class and become well-acquainted with its documentation. Using that library, design and develop a website. You may also use another library you have researched independently, so long as it is well documented.

Libraries

  • Three.js: Docs · Example: Radio Garden
  • Matter.js: Docs · Example: bong.international
  • ml5.js: Docs · Example: Webcam image recognition

Honorable mentions

  • anime.js: animation for HTML elements and CSS. Docs
  • Chart.js: charts and graphs from data. Docs
  • Tone.js: sound and music in the browser. Docs

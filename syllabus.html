Project 1: Hello World (Aug 27 – Sep 10)

Using your existing knowledge of HTML and CSS (and JavaScript, if you like), create a homepage that represents you in some way. It could introduce yourself, explore an interest or obsession, or give you a chance to realize an idea you've had. Think of it as making a place for yourself on the web.

This site will also be used to catalogue the projects for the rest of the semester, so it can keep developing as we continue.

For inspiration check out: https://geocities.restorativland.org

You will learn: HTML structure, CSS styling, Site navigation, Variables, functions and click events

Part 1 — Relearning the web (Weeks 1–3)

Students are re-introduced to basic HTML + CSS concepts and are asked to produce a simple "homepage" site to catalogue the projects for the rest of the semester. If students feel comfortable, they are given the opportunity to integrate JavaScript into their site. An emphasis is given on foundational web knowledge and clear code to provide a framework for more advanced work in the coming weeks.

Project 2: Generative Pattern (Sep 10 – Oct 1)

You will write a JavaScript program which uses loops and if statements to create a modular generative pattern. You will design at least one single pattern unit (a module) (think: div) that changes over the course of its output.

Your unit should iterate at least 100 times. With each iteration, your unit should somehow modify itself (content or CSS attributes: size, color, rotation, shape, texture). Your pattern should have at least 2 variables of change (ex: content, color), is allowed to repeat itself (i.e. be a pattern), and is allowed to be as abstract or literal as you want (it can tell a story, or it can be an exercise in form). The goal of this project is to use JavaScript to dynamically append HTML elements and programmatically alter their attributes. This project will also utilize JavaScript to explore techniques of animation and interactivity.

You will learn: Loops and arrays, Timing with setTimeout(), Randomness with Math.random(), Changing CSS with JavaScript

Part 2 — JavaScript, iteration, and movement (Weeks 3–6)

Students are introduced to programming concepts: data storage/structures, loops, and functions and explore their visual potential through the development of generative patterns, animations, and modular abstractions. Emphasis is given towards understanding data types, storing values, and manipulating CSS (units and classes) with JavaScript.

Project 3: Garden (Oct 1 – Oct 22)

Using what you have learned about event listeners, mouse coordinates, and dynamically creating and appending HTML elements, create a virtual garden which implements the ability to render and place elements where you click your mouse.

You will learn: Event listeners, Event objects and mouse coordinates, Creating and placing elements, Arrays of objects and forEach

Part 3 — Interaction (Weeks 6–9)

Students are introduced to event listeners and mouse interaction through a series of small interactive demos.

Project 4: Sender Receiver (Oct 22 – Nov 12)

Design and develop a website which incorporates an external data feed, using one of the APIs discussed in class. You may also use another API or service that you have researched independently, so long as it provides a live data stream to work with. Consider how your specific design logic might change the meaning of said data, and how the user may (or may not) interact with the feed as they engage with your site.

You will learn: APIs and fetch(), Asynchronous code and JSON, Turning data into elements on the page, Saving data with localStorage

Part 4 — Fetching (Weeks 9–12)

Students are introduced to JavaScript as a method of data management. Students are given demos exploring asynchronous functions, APIs, and localStorage to gain an understanding of fetching and pushing data.

Project 5: Library Interface Project: Globe (Nov 12 – Dec 10)

Using an API to fetch place-based data and the Three.js library, design and build an interactive 3D globe that catalogues a network of real places connected by a shared purpose — a resource, a service, a community, a cause. Consider how the look of your globe reflects the topic you are working with, and design an interface for how users discover and access the data behind each place.

You will learn: Fetching and mapping geographic data, 3D coordinate math (latitude/longitude to Cartesian), Raycasting and interaction in 3D, Reading Three.js documentation

Part 5 — The world of the web (Weeks 12–15)

After gaining an understanding of how to manipulate CSS through plain JavaScript, students are introduced to JavaScript libraries through a series of small demos. Students are expected to select and become well-acquainted with the documentation of one library through an interface-based project for the remainder of the course.
